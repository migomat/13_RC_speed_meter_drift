Kalibracja montażu z tego wyścigu

Użyj nagrania spokojnej jazdy bez driftu (kilka okrążeń, zwykłe zakręty) zaraz po zamontowaniu Xiao w aucie. Kierunek przyspieszenia w zakrętach wyznacza, jak płytka leży w aucie – od tego zależy kąt driftu. Z tego samego nagrania wychodzi kierunek skrętu (normalny / odwrócony).

Liczone z zakresu widocznego na wykresach – zaznacz palcem fragment ze spokojną jazdą (bez driftu), potem „Wyznacz”.

Wygląd

Synchronizacja (GitHub)

Starty i wyścigi wspólne dla telefonu i komputera – przez prywatne repozytorium na GitHubie. Token zostaje tylko na tym urządzeniu.

Jak zdobyć token
  1. github.com → zdjęcie profilu → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nazwa np. „x4f”, ważność np. 1 rok.
  3. Repository access: Only select repositories → x4f-dane.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token, skopiuj i wklej tutaj – na każdym urządzeniu (telefon, komputer).
